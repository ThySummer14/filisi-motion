A QUICK START

你的第一段动效

  1. 添加文字、图形或导入图片。在画布拖动，右侧精调尺寸与位置。
  2. 将播放头移到开头，点击属性旁的 ◇ 添加关键帧。
  3. 移动播放头，再修改同一属性。已有动画的属性会自动写入关键帧。
  4. 展开图层下的属性轨道，拖动菱形改时间；选中菱形后可改值和缓动。点击「曲线编辑器」可拖动键点与贝塞尔手柄。
  5. 保存工程为 .filisi 文件，或导出 WebM、GIF、PNG。

这是独立开发的二维动效编辑器预览版，不兼容 AE 工程。现支持视频与音频素材的裁剪、拆分、原声混音；尚不含遮罩、3D 或 MP4 编码。WebM 需要浏览器支持 MediaRecorder；GIF 可用作跨浏览器备用，但色彩与尺寸有限。建议桌面 Chrome / Edge；Safari 视频编码能力需单独验证。

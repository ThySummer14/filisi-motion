# 使用指南

## 工作台

左侧添加素材与设置合成；中间是可拖动对象的画布；右侧编辑选中图层；底部处理时间。窄屏会纵向排列面板，推荐桌面窗口宽度至少 1100 px。

时间以秒储存，播放头和拖动操作按当前 FPS 吸附。显示时间格式为「分:秒:帧」。图层在入点可见、出点不可见；播放头停在合成结束处时显示背景是正常的出点行为。

## 图层与文字

添加的对象位于合成中心。时间线顶部是画面最上层。「上移 / 下移」改变合成叠放顺序。锁定后不能拖动或编辑该图层，先解锁再操作。

文字支持多行、字重、大小与左中右对齐。文字框宽度决定对齐参照，不会自动换行或裁切；需要换行时直接回车。系统字体在不同操作系统可能不同。

图片仅接受 PNG、JPEG、WebP，嵌入 `.filisi` 工程；不会从外部 URL 拉取。为了控制内存，不接受 SVG 或超大图片。

## 关键帧

1. 选中图层，将播放头放到起点。
2. 点击位置、缩放、旋转、不透明度或模糊右侧的「◇」。
3. 将播放头移到另一个时刻，修改同一属性数值。
4. 只要该属性已有关键帧，修改数值就会写入当前时刻。没有关键帧的属性默认修改静态值。
5. 「自动关键帧」开启后，没有动画的变换属性也会在当前时间写入关键帧。

菱形为绿色表示该属性有动画，深绿底表示当前时刻有关键帧。再次点击会删除当前关键帧；删除最后一帧时，保留当前数值作为静态值。

点击时间线上的菱形，会定位播放头并打开关键帧属性。缓动设置控制「此帧到下一帧」；最后一帧的缓动没有可见效果。

- **线性**：匀速变化。
- **缓入 / 缓出**：三次曲线加速 / 减速。
- **缓入缓出**：两端平稳、中间较快。
- **保持**：到下一关键帧时立即切换。

拖动菱形改变时间；落到已有同属性关键帧的位置会替换它。Delete 删除选中菱形；先点击图层名称再 Delete 则删除图层。

## 时间线与剪裁

点击或拖动上方时间标尺定位。拖动图层条中间可移动入点、出点及关键帧；拖动条的两端只裁剪可见时间，不改变关键帧。超出合成范围的关键帧移动会被限制在合成边缘，请用撤销恢复不期望的操作。

缩短合成时长会裁剪超出的图层与关键帧；这可以撤销。更改画布尺寸不会自动缩放已有对象。

## 保存与恢复

「保存工程」下载 `.filisi` JSON，其中包括图片和全部关键帧。「打开」可在本设备或另一设备重开。

浏览器自动存档是便利功能，不是备份。大图可能超过 LocalStorage 配额，此时顶部会提醒手动保存。关闭未下载保存的工程时浏览器可能显示离开提醒。

撤销 / 重做保存的是操作前的工程快照，最多 60 步。导入图片较多时请及时保存，历史快照会增加内存占用。

## 导出

- **WebM**：实时录制原合成尺寸。请保持页面前台。移到后台时会终止并显示原因，避免交付截断片段。编码能力由浏览器提供；无 WebM 能力时按钮不可用，可改用 GIF 或 PNG。
- **GIF**：逐帧渲染，固定 256 色会产生色阶，文件通常较大。宽度越高、合成越长，资源消耗越高。
- **PNG**：导出当前帧，无画布选择框。

导出期间可以取消；同一时刻只能运行一个导出。导出使用独立工程快照，不改变预览播放头。下载是否被浏览器保存到磁盘取决于浏览器下载设置。

## 快捷键

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 保存 / 打开 | ⌘S / ⌘O | Ctrl+S / Ctrl+O |
| 撤销 | ⌘Z | Ctrl+Z |
| 重做 | ⇧⌘Z | Ctrl+Shift+Z / Ctrl+Y |
| 复制图层 | ⌘D | Ctrl+D |
| 播放 / 暂停 | 空格 | 空格 |
| 前后 1 帧 | ← / → | ← / → |
| 前后 10 帧 | Shift+← / → | Shift+← / → |
| 删除选中关键帧或图层 | Delete / Backspace | Delete / Backspace |

在输入框或对话框中，这些快捷键不会抢占文字编辑。
